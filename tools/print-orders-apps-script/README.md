# קליטת הזמנות הדפסה ל-Google Drive (Apps Script)

הסקריפט מקבל מהדף `/plan-printing/` את פרטי ההזמנה ואת הקבצים, ושומר אותם בתיקייה נפרדת לכל הזמנה בתוך תיקיית Drive של המשרד. אפשר גם לשלוח התראה במייל.
**אין בקוד סודות.** מזהה התיקייה וכתובת ההתראה נשמרים ב-Script Properties ולא בריפו.

## התקנה (פעם אחת, מחשבון המשרד)
1. נכנסים ל-Google Drive עם חשבון המשרד ויוצרים תיקייה, למשל `הזמנות הדפסה מהאתר`. מעתיקים את ה-ID שלה מהכתובת (`drive.google.com/drive/folders/<ID>`).
2. נכנסים ל-https://script.google.com ופותחים פרויקט חדש בשם `hram-print-orders`.
3. מוחקים את התוכן של `Code.gs` ומדביקים במקומו את הקובץ `Code.gs` מהתיקייה הזו.
4. ⚙️ Project Settings ← Script Properties ← מוסיפים:
   - `FOLDER_ID` = ה-ID מסעיף 1 (חובה)
   - `NOTIFY_EMAIL` = `office@hram.co.il` (לא חובה. בלי הערך הזה לא נשלחת התראה)
5. Deploy ← New deployment ← סוג **Web app**:
   - Execute as: **Me** (חשבון המשרד)
   - Who has access: **Anyone**
   - לוחצים Deploy ומאשרים את ההרשאות: Drive, שליחת מייל, וחיבור לשירות חיצוני (UrlFetch, להעלאה ל-Drive API).
6. מעתיקים את ה-Web app URL (`https://script.google.com/macros/s/.../exec`).
7. בקובץ `plan-printing/index.html` מחליפים ב-`CONFIG` את `APPS_SCRIPT_URL: "APPS_SCRIPT_URL_TBD"` בכתובת מסעיף 6. הכתובת ציבורית ואינה סוד.
8. בודקים: פותחים את הכתובת בדפדפן. צריך להופיע `{"ok":true,...}`. אחר כך שולחים הזמנת ניסיון עם PDF קטן מהדף, ובודקים שנוצרה תיקייה ב-Drive.

## עדכון קוד
אחרי שינוי ב-`Code.gs`: Deploy ← Manage deployments ← עריכה ← Version: New version. כך הכתובת נשארת אותה כתובת.

## מגבלות
- גודל מרבי לקובץ: **45MB** (`MAX_FILE_MB`, זהה בסקריפט ובאתר). קובץ גדול יותר הלקוח שולח בקישור.
- ההעלאה מתבצעת במקטעים של 3MB, ולכל מקטע יש בקשה נפרדת. הסקריפט מעביר כל מקטע ישירות ל-Drive בהעלאה מתחדשת (resumable upload), כך שהוא לא מחזיק את כל הקובץ בזיכרון ונשאר בתוך מגבלות הבקשה וזמן הריצה של Apps Script.
- מכסות Google לחשבון רגיל: זמן ריצה ושליחת מיילים יומית (כ-100 מיילים ביום לחשבון Gmail רגיל, יותר ב-Workspace). למשרד קטן זה מספיק.
- הכתובת פתוחה ל-"Anyone", ולכן כל אחד יכול לשלוח אליה. יש הגנות בסיסיות: רק PDF/DWF, מספר הזמנה בתבנית קבועה, וכתיבה רק לתת-תיקיות של `FOLDER_ID`. אין CAPTCHA. אם יגיע ספאם, אפשר להוסיף reCAPTCHA או להשבית את הפריסה.
- אם הכתובת לא הוגדרה או שההעלאה נכשלה, הדף מציג ללקוח שליחה במייל או בוואטסאפ.
