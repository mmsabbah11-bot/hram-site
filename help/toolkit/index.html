מה בחבילה

  • HRAM_TrafficTools.lsp: כלי LISP ל-AutoCAD.
  • HRAM_Parking_Calculator.xlsx: מחשבון דרישת חניה ומאזן מול התכנון.
  • HRAM_Road_Quantities_Estimate.xlsx: כתב כמויות ואומדן לעבודות כביש ופיתוח.
  • קובצי README, הוראות התקנה ו-LICENSE.txt (הסכם הרישיון).

התקנת כלי ה-LISP (כ-2 דקות)

  1. העתיקו את HRAM_TrafficTools.lsp לתיקייה קבועה, למשל C:\HRAM\.
  2. ב-AutoCAD הקלידו APPLOAD, בחרו את הקובץ ולחצו Load.
  3. לטעינה אוטומטית בכל פתיחה: בחלון APPLOAD לחצו Startup Suite › Contents › Add והוסיפו את הקובץ.
  4. אם מופיעה אזהרת אבטחה: הקלידו OPTIONS, עברו ללשונית Files › Trusted Locations והוסיפו את C:\HRAM\.
  5. הקלידו HRHELP כדי לראות את רשימת הפקודות.

דרישות: AutoCAD מלא או Civil 3D על Windows (נבדק על 2023 ו-2026). ב-AutoCAD LT, LISP נתמך רק מגרסה 2024. יחידות השרטוט: מטרים.

רישיון

כלי ה-LISP וקובצי האקסל אינם דורשים מפתח הפעלה. הרישיון הוא לרוכש בלבד, לפי הסכם הרישיון שמצורף בקובץ LICENSE.txt, ואין להפיץ את הקבצים.
