מה כלול בחבילה

  • Haram Parking Suite 2.0, רישיון לשנה: ראו מדריך ההתקנה והפעלת הרישיון.
  • HRAM Traffic Toolkit v1: ראו מדריך ערכת הכלים.
  • תבנית אומדן הסדרי תנועה זמניים: ראו מדריך התבנית.
  • גישה לקורס תכנון הסדרי תנועה עם פתיחתו: ראו עזרה לקורס.

סדר התקנה מומלץ

  1. התקינו את Haram Parking Suite והפעילו את הרישיון בפקודה DDP_LICENSE.
  2. טענו את HRAM_TrafficTools.lsp בפקודה APPLOAD והוסיפו אותו ל-Startup Suite.
  3. שמרו את קובצי האקסל בתיקיית עבודה קבועה, ופתחו אותם ב-Excel.

רק Parking Suite דורש מפתח רישיון. החבילה היא רישיון שנתי ומתחדשת במחיר השנתי של החבילה.
