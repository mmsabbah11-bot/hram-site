מדריך: Haram Parking Suite 2.0

התקנה, הפעלת רישיון ורשימת פקודות לתוסף החניות, הנגישות והתמרור ל-AutoCAD ו-Civil 3D.

התקנה

  1. סגרו את AutoCAD.
  2. חלצו את קובץ ה-ZIP שהורדתם לתיקייה כלשהי.
  3. הריצו את install_for_customer.bat. הקובץ מעתיק את התיקייה HaramParkingSuite.bundle אל %APPDATA%\Autodesk\ApplicationPlugins.
  4. לחלופין, העתיקו ידנית את התיקייה HaramParkingSuite.bundle אל %APPDATA%\Autodesk\ApplicationPlugins (למשתמש הנוכחי) או אל C:\ProgramData\Autodesk\ApplicationPlugins (לכל המשתמשים במחשב).
  5. פתחו את AutoCAD. התוסף נטען אוטומטית ולשונית Haram Pro מופיעה ברצועה. הקלידו DDP_HELP לעזרה.

התוסף בוחר אוטומטית את הגרסה המתאימה: ‎.NET Framework 4.8 ל-AutoCAD/Civil 3D 2021–2024, ו-‎.NET 8 ל-2025 ואילך. נדרש Windows 64 ביט. AutoCAD LT אינו נתמך.

הפעלת הרישיון

  1. ב-AutoCAD הקלידו DDP_LICENSE. יוצג מזהה המחשב (Machine ID).
  2. שלחו את מזהה המחשב ואת מספר החשבונית ל-office@hram.co.il.
  3. תקבלו מפתח רישיון שנתי חתום. הריצו שוב DDP_LICENSE והדביקו את המפתח.
  4. תאריך התפוגה יוצג על המסך. 30 יום לפני תום התוקף תופיע התראת חידוש.

לפני ההפעלה עומדים לרשותכם 14 ימי ניסיון. אחרי תום תוקף הרישיון פקודות התכנון נחסמות, ורק DDP_HELP ו-DDP_LICENSE ממשיכות לעבוד. המפתח אישי ומשויך למחשב. אין להעביר אותו לאחרים.

ספריית תמרורים ויומן תקלות

  • הפקודה DDP_SIGN_ADD משתמשת בקובץ הבלוקים TR_Block_140305.dwg. אם הוא לא נמצא בתיקיית התוסף, תתבקשו לבחור אותו בפעם הראשונה.
  • במקרה של תקלה, צרפו לפנייה את קובץ היומן %LOCALAPPDATA%\HaramPro\haram.log.
