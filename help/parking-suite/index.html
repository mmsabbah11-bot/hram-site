מדריך: HRAM Pro Suite 3.0.2

התקנה, הפעלת רישיון ורשימת פקודות לתוסף החניות, הנגישות, מעטפות התנועה וכתב הכמויות ל-AutoCAD. גרסה 3.0.2 מחליפה את Haram Parking Suite 2.x.

התקנה

  1. סגרו את AutoCAD.
  2. הריצו את קובץ ההתקנה HRAM_Pro_Suite_3.0.2_Setup.exe שקיבלתם. ההתקנה היא למשתמש הנוכחי, וגרסה קודמת של התוסף מועברת לתיקיית ארכיון ואינה נמחקת.
  3. לחלופין, העתיקו ידנית את התיקייה HaramParkingSuite.bundle אל %APPDATA%\Autodesk\ApplicationPlugins (למשתמש הנוכחי) או אל C:\ProgramData\Autodesk\ApplicationPlugins (לכל המשתמשים במחשב).
  4. פתחו את AutoCAD. התוסף נטען אוטומטית ולשונית Haram Pro מופיעה ברצועה. הקלידו DDP_HELP לעזרה.

מי שמשתמש כבר ב-Parking Suite 2.x אינו צריך להסיר אותו: ההתקנה מחליפה אותו, והרישיון השנתי ממשיך לפעול. התוסף בוחר אוטומטית את הגרסה המתאימה: ‎.NET Framework 4.8 ל-AutoCAD/Civil 3D 2021–2024, ו-‎.NET 8 ל-2025 ואילך. נדרש Windows 64 ביט. AutoCAD LT אינו נתמך.

הפעלת הרישיון

  1. ב-AutoCAD הקלידו DDP_LICENSE (קיצור: HRLIC). יוצג מזהה המחשב (Machine ID).
  2. שלחו את מזהה המחשב ואת מספר החשבונית ל-office@hram.co.il.
  3. תקבלו מפתח רישיון שנתי חתום. הריצו שוב DDP_LICENSE והדביקו את המפתח.
  4. תאריך התפוגה יוצג על המסך. 30 יום לפני תום התוקף תופיע התראת חידוש.

לפני ההפעלה עומדים לרשותכם 14 ימי ניסיון. אחרי תום תוקף הרישיון פקודות התכנון נחסמות, ורק DDP_HELP ו-DDP_LICENSE ממשיכות לעבוד. המפתח אישי ומשויך למחשב. אין להעביר אותו לאחרים.

ספריית תמרורים ויומן תקלות

  • הפקודה DDP_SIGN_ADD משתמשת בקובץ הבלוקים TR_Block_140305.dwg. אם הוא לא נמצא בתיקיית התוסף, תתבקשו לבחור אותו בפעם הראשונה.
  • במקרה של תקלה, צרפו לפנייה את קובץ היומן %LOCALAPPDATA%\HaramPro\haram.log.
